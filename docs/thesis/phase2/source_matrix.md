## 주장 추적 원칙

1. 학술·표준 근거는 설계 선택과 해석에 사용한다.
2. UNIBUS의 성능·기능·보안 결과는 저장소와 실측 자료로만 주장한다.
3. 사용자 만족도, 운행 정확도, 안전성은 현장 자료가 없으므로 평가 결과로 제시하지 않는다.
4. 논문 작성 시 각 결과표에 측정 환경, 반복 횟수, 적용 범위를 함께 표시한다.
