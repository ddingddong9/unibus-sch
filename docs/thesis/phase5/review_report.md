# 최종 내부 심사 보고서

## 심사 범위

- 대상: `manuscript.md`, 최종 DOCX, 렌더링 PDF, 근거 문서와 시험 스크립트
- 관점: 연구방법, 주장-근거 정합성, 인용 무결성, 재현성, 보안, 편집 품질
- 판정: **수정 후 제출 가능**

## 주요 판정

1. 연구방법은 설계과학 연구로 명시되어 있고 문제 인식, 인공물 설계, 시연, 정량 평가, 한계의 흐름이 일관된다.
2. 학교 측의 운전 중 기사 조작 제약 때문에 현장 사용자 시험을 수행하지 못했다는 사실을 초록, 평가, 논의, 결론에서 반복해 명시하였다. 사용성, 실제 ETA 정확도, 운영 효율, 안전 효과는 입증한 것으로 서술하지 않았다.
3. 성능과 품질 수치는 저장소 명령, 원격 Supabase 검사, Lighthouse 반복 측정에서 얻은 값으로 범위를 한정했다. 21개 알고리즘 시나리오는 합성 입력에 대한 기능 검증이며 실제 GPS·교통 상황의 정확도를 대표하지 않는다.
4. 학술 자료 14건과 공식 표준·기술 문서 8건을 원문 DOI 또는 발행기관 페이지로 확인했다. 참고문헌 22건은 모두 본문에서 사용되며, 본문에 등장하는 저자-연도 인용은 참고문헌과 대응한다.
5. 보안 결과는 제한적 소스·스키마·비인증 요청 검토로 한정했다. 침투시험, 클라우드 조직 권한, DDoS, 공급망 전체를 검사한 것으로 확대 해석하지 않았다.

## 잔여 위험과 제출 전 확인

- 원격 운영 환경에서 과거 기본 관리자 비밀번호가 사용되지 않는지 확인하고 관리자 비밀번호 회전 및 기존 세션 무효화를 수행해야 한다.
- 실제 학교 운영 자료가 확보되면 차량 단말 위치 수집, 정류장 체류시간, GPS 지도 정합, 학생·교수 과업 시험을 별도 연구로 수행해야 한다.
- 제출 연도가 확정되면 표지·승인란 날짜와 개발 종료 기준일을 학과 안내에 맞게 갱신해야 한다.
- 지도·열차 시간표·운행 규칙이 실제 운영 자료와 일치하는지는 학교 담당자의 최종 확인이 필요하다.
